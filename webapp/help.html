Staff Guide

This guide explains how to use each part of the system, assuming you have already logged in successfully.

1. Logging In

  1. Enter the username and password given to you by your Administrator.
  2. Click Log In. If the details are wrong, an error message appears below the password box.
  3. If your account has been deactivated, contact an Administrator.

2. Register New Appointment

  1. From the Main Menu, click Register New Appointment.
  2. Fill in the patient's name, address and contact number. If this contact number already exists, their saved details are reused/updated automatically.
  3. Choose the Dentist and Treatment Type from the drop-down lists.
  4. Choose the appointment date and a 15-minute time slot between 08:00 and 17:00.
  5. Click Register Appointment. If the dentist is already booked for that exact time, you'll be asked to pick a different slot — this is how the system prevents double bookings.
  6. Note the Appointment Number shown — the patient needs it for billing.

3. Appointment Details / Calculate & Print Bill

  1. From the Main Menu, click Appointment Details / Bill.
  2. Type the appointment number and click Search.
  3. If no bill exists yet, optionally tick the returning-patient discount box, then click Generate Bill.
  4. If a bill already exists, it's shown automatically.
  5. Click Print Bill to print the receipt (uses your browser's normal print dialog).

4. Reports

  1. From the Main Menu, click Reports.
  2. Daily Schedule: pick a date and click Run Report.
  3. Patient History: search for a patient, select them, then Run Report.
  4. Revenue Summary: pick a date range for total income and a daily breakdown.
  5. Dentist Workload: pick a date range to see appointment counts per dentist.
  6. Use the Print button on any tab to print that table.

5. Manage Staff Accounts (Administrators only)

  1. From the Main Menu, click Manage Staff Accounts.
  2. Use the form at the bottom to create a new Receptionist or Administrator login.
  3. Use the Activate/Deactivate button next to any account to enable or block access without deleting it.
  4. Use the Reset Password button if a staff member forgets their password.

6. Logging Out and Exiting

  1. Click Log out (top-right of any page) to return to the login screen.
  2. Click Exit System on the Main Menu to end your session.

Tips

  • Every screen shows a short error message if something is missing or invalid — read it before trying again.
  • Keep a note of each appointment number after registering it — it's the fastest way to find the record again.
